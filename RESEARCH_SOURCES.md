# Focused production research source index

Checked 2026-10-25. This is a selected-section review, not a full-book or exhaustive filmmaking survey. Only original guidance and links are retained; embedded films, images and audio were not watched or licensed. KU licensed text is excluded from this commercial production toolkit.

Status vocabulary: **queued** = identified but not read here; **reviewed** = named text sections retrieved; **applied** = an original rule added to guidance; **verified** = a specific check run against an artifact. These stages do not imply verified production quality. No source below has been verified by a new rendered performance. Test verification is recorded separately in the change evidence.

The cue-loss regression, separate hearing gate and continuous-binding checks are original engineering applications of the accepted production correction. Metadata tests verify record consistency, not the sources' artistic advice or model performance. Playable intention, energy arcs and cut choices remain editorial hypotheses to audition against the project's actual approved script.
