# Auditor and independent checker task briefs

Use private copies with the current owner-approved scope. These are distinct review roles; names alone do not prove independence or actual observation. Record evidence limitations honestly. Neither role may authorize spending, retries or publication.

## Prompt auditor — before generation

Owner / attempt ID / immutable prompt version and hash:
Assigned reviewer / UTC audit time:
Approved brief and reference versions:

Inspect the exact prepared prompt, ordered references and actual supported payload. Check the approved brief, identity/wardrobe/location/prop/ensemble readiness, binding roles, model/settings, exact dialogue and speaker order, performance/reaction, ongoing movement when requested, purposeful coverage and literal uppercase CUT at every shot transition. Keep mechanical QA checks from accidentally directing a held pose. Inspect actual reference assets; populated metadata cannot replace them. Record missing information as unresolved. Distinguish approved exploration from production-ready claims.

Return pass / revise / unverified, one result per schema check, specific findings and evidence. Save an `audit` record bound to the immutable attempt before any job begins, and run the prompt gate. An amended prompt/payload needs a new attempt and appropriate prompt version plus a fresh audit. Quote/transfer side effects, spending and execution permission remain separate gates.

## Result/failure checker — after output or provider failure

Owner / attempt ID / independent reviewer / UTC review time:
Exact job receipt / output asset and hash / duration:
Available evidence and missing coverage:

Independently review all attempts, including failures and fragments, against the approved brief and audit. Watch actual motion at normal speed, inspect critical contacts/seams, and directly listen to the entire output when audio is expected or present. Check performance, identity, scene geography, props, angle changes, exact words/speakers/voice, timing, effects and ambience. Use the existing continuity and final-export gates as applicable. Do not infer quality from metadata, an audio stream, ASR, sampled frames or job completion.

Return accept / reject / keep_fragment / repair / unverified. Record observed defects with output-relative timestamps and evidence first; separately record suspected causes, confidence or unknown, supporting/counter-evidence and the smallest controlled test that could distinguish hypotheses. Do not assume long prompts caused failure. Mark unavailable audio/visual evidence unverified. A provider failure without an output gets job/receipt evidence and an unresolved result, not an invented review.

Preserve owner feedback separately, append review records and run the result gate. Propose the smallest repair; link any separately authorized retry to its parent attempt and exact changes. Never overwrite the earlier prompt, receipts, costs or findings. Preserve originals and private context. A declaration-gate pass is not authenticated approval or release authority.
